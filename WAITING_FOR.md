## How to Use This File

**Add items when:**
- You send an email/message and need a response
- Someone commits to delivering something
- You're blocked waiting for external input

**Remove items when:**
- Response received (update relevant files with new info)
- Item becomes irrelevant
- Moved to a project or captured elsewhere

**During morning check-in:** Review chase dates. Anything overdue? Anything due today?
