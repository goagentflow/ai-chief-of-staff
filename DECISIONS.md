## Why This File Matters

You're strong at problem-solving in the moment but weak at recalling what you decided and why. This file is your external memory for decisions. When future-you asks "why did we do it that way?", the answer is here.

**The reasoning is the most important part.** The decision itself is often obvious in hindsight - it's the context and trade-offs that get lost.

### Pricing Model for New Service
- **Context:** Client asked for AI training but we've never packaged this before
- **Options:**
  1. Day rate (£1,500/day) - Simple, familiar. Risk: undervalues IP.
  2. Project fee (£4,500 for 3 sessions) - Packages the value. Risk: scope creep.
  3. Retainer + workshops (£2k/month + £500/session) - Ongoing relationship. Risk: too complex for a first engagement.
- **Leaning towards:** Option 2 - starts simple, proves value, can evolve
- **Decide by:** Before proposal goes out (15 Jan)
- **Blockers:** Need to understand their budget expectations

## How to Use This File

**Add decisions when:**
- You're weighing up options and need to think it through
- You've just made a call and want to capture why
- Something is blocked because you can't decide

**During morning check-in:** Check for decisions with imminent deadlines

**Archive when:** Decisions older than 2-3 months move to DECISIONS-ARCHIVE.md (if you create one) - the reasoning is still valuable for reference
