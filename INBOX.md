## How to Use This File

**Dump things here when:**
- You think of something but don't have time to file it properly
- Something comes up that needs action but you're in the middle of something else
- You need a quick place to capture before it escapes

**Process during morning check-in:**
- Move tasks to PROJECTS.md if they're project-related
- Move ideas to IDEAS.md if they need to marinate
- Move waiting items to WAITING_FOR.md
- Delete or action anything that can be done in 2 minutes

**The goal:** INBOX.md should be nearly empty by end of morning check-in. It's a holding pen, not a permanent home.
